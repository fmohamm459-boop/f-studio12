# F Studio — Foundation Scaffold

This is the Phase 9.3.3 Stage 1 foundation scaffold only. No pages, business logic, database
models, or Client Review authentication are implemented — see
`F_Studio_Phase_9_3_3_Stage1_Foundation_Report.md` for the full report, and
`F_Studio_Phase_9_3_3_Architecture_Decision_Record.md` for the binding scope decisions this
scaffold follows.

## Getting started (once network/package installation is available)

```bash
npm install
npm run dev
```

Dependencies are declared in `package.json` but were not installed in the environment this
scaffold was generated in (no network access). Run `npm install` before `npm run dev`.
